# ⚔️ Pixel Crawler - RPG Typing Battle (Web & Mobile Edition)

Game edukasi mengetik interaktif bergaya Retro Pixel Art RPG 2D. Dapat dimainkan secara langsung di browser Desktop (PC / Laptop) maupun Gadget (Smartphone / Tablet).

🎮 **Live Demo:** [https://pptqjamalyusuf.github.io/RPG-Typing/](https://pptqjamalyusuf.github.io/RPG-Typing/)

---

## 🌟 Fitur Utama
1. **Multi-Platform & Gadget Ready:**
   - **Laptop / Komputer:** Ketik langsung dengan keyboard fisik.
   - **HP / Tablet:** Dilengkapi *Virtual Touch Keyboard* retro responsif di layar dan dukungan keyboard bawaan perangkat.
2. **4 Hero Party System:**
   - 🛡️ **Tulien (Knight)** - *Slash / Holy Greatsword Cleave* (VFX Impacts)
   - ✨ **Ayaka (Wizard)** - *Arcane / Celestial Nova Pillar* (VFX Priest)
   - 🗡️ **Cleome (Rogue)** - *Pierce / Shadow Dagger Slices* (VFX Slash)
   - 🔨 **Sabin (Warrior)** - *Crush / Blazing Dragon Fist* (VFX Fire Explosions)
3. **Parallax Background:** Pemandangan hutan *Whitewood Vale* dengan awan bergerak dinamis.
4. **Boss Wave Progression:** Musuh bertingkat (*Beast Lord*, *Veritas*, *Skeleton Mage*, *Demon General*) dengan bar darah dan serangan berwaktu.
5. **Kurikulum Bahasa & Kosakata:**
   - 🟢 Program 1: Kata Dasar (3-4 Huruf)
   - 🟡 Program 2: Petualang Dungeon (5-7 Huruf)
   - 🔴 Program 3: Legenda Kerajaan (8-12 Huruf)
   - ⚔️ Program 4: RPG English Adventure
6. **Web Audio Synthesizer:** Efek suara benturan pedang, sihir kristal, dan ledakan api 100% diproduksi secara dinamis menggunakan Web Audio API tanpa file audio eksternal.

## 🚀 Cara Menjalankan
Cukup buka file `index.html` di browser apa pun, atau aktifkan fitur **GitHub Pages** pada repositori ini:
1. Masuk ke tab **Settings** > **Pages** di repositori GitHub.
2. Pilih Branch: `main` / Folder: `/(root)` lalu klik **Save**.
3. Buka URL GitHub Pages yang dihasilkan.
